# Local Message Simulator

A static iPhone-ready Progressive Web App for a local messaging simulation. It does not send SMS, phone calls, or messages. Contact and conversation records are imported and stored on the device.

## Free GitHub Pages setup

The repository root contains the built static app. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Wait for GitHub Pages to publish the HTTPS URL.

## Private starter data

The public app files and source archive do not include contact or conversation records. Import the separate `Aashna-Mam-local-starter.json` on the target device. Keep that private JSON out of this repository.

## Source

Download `local-message-simulator-source.zip` for the React and TypeScript source project. That archive also excludes the private starter data.
